# Source Governance

Use current law or government sources first, followed by official provider
pages, university/Extension sources, verified partner knowledge, reputable
secondary explanations, then directories or promotional submissions.

Every source records resource types, inclusion basis, multidimensional
audiences, cost model, verification requirement, status, authority, refresh
trigger, citation rule, restrictions, and failure modes.

Closed, archived, quarantined, and unverified records cannot be presented as
currently available. Cost is always verified before recommendation.

The supplied workbook contains 171 source records while the PDF headline
reports 191. Three records have non-HTTP canonical destinations, and two use a
category absent from the category taxonomy. Validation preserves these as
visible review warnings.
