# Minimal Intake

Collect the user's type, business stage, defined goal, location, timing,
readiness, budget, and accessibility constraints only when each answer can
change eligibility, ranking, verification, or the next action.

If no goal is clear, do not force the user to invent one. Offer a small set of
goal directions grounded in their context. Give each option a first experiment
and measurable success signal. Let the user select, revise, combine, or defer
the options before resource matching begins.
